What Wally Can Do

Everything Your Server Needs

From powerful moderation tools to fun community features, Wally Bot has it all — completely free.

🛡️

Moderation Suite

Kick, ban, mute, warn, softban, mass ban, and more. Full warning history per user with DM notifications. Keep your server clean effortlessly.

🤖

Auto Moderation

Automatically filter bad words, block spam, and remove Discord invite links. Configurable per-server with live audit logging.

🎉

Giveaways

Start, end, and reroll giveaways with full duration support. Winners selected fairly at random with multi-winner support.

💤

AFK System

Set an AFK status with a reason. Your nickname gets updated automatically and anyone who pings you gets notified with your reason and time away.

📋

Reaction Roles

Assign roles to members automatically when they react to a message. Fully configurable and supports unlimited emoji-role pairs.

🔗

Server Link Selector

Beautiful Sapphire-style dropdown embed to showcase and link partner Discord servers. Supports up to 25 servers with custom descriptions.

📊

Polls & Schedules

Create yes/no polls or multi-option polls in seconds. Schedule messages to auto-send at any time with full duration syntax support.

📝

Custom Commands

Build your own server commands with custom responses. Create unlimited prefix commands unique to your server.

📜

Rules & Logging

Post formatted server rules, manage channel permissions, and log every server event — joins, bans, edits, deletes — to a dedicated log channel.

All Moderation Utility Fun Admin
/kick Kick a member from the server with an optional reason
/ban Ban a member and optionally delete their recent messages
/mute Timeout a member for a set duration (e.g. 10m, 2h)
/warn Issue a warning to a member with DM notification
/purge Bulk delete 2–100 messages from a channel
/softban Ban then unban immediately to clear a user's messages

/remind Set a personal DM reminder for any duration

/poll Create a yes/no or multi-choice poll instantly
/automod Configure bad words, spam limits, and invite blocking
/reactionrole Assign roles to emoji reactions on any message
/serverlink Post a Sapphire-style server link dropdown selector
/schedule Schedule a message to send at a future time
