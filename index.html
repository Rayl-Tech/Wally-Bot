Command Reference

Every Command, Right Here

Prefix w! or use slash / — all commands are available both ways.

/kickModSlash
w!kick @user [reason]
Kick a member from the server with an optional reason.
/banModSlash
w!ban @user [reason]
Ban a member from the server permanently.
/unbanModSlash
w!unban <user_id>
Unban a user by their Discord ID.
/muteModSlash
w!mute @user <duration> [reason]
Timeout a member. Supports 10s, 5m, 2h, 1d format.
/unmuteModSlash
w!unmute @user
Remove timeout/mute from a member.
/warnModSlash
w!warn @user <reason>
Warn a member and DM them the reason. Warns are tracked.
/warningsModSlash
w!warnings @user
View all warnings on record for a member.
/clearwarnsModSlash
w!clearwarns @user
Clear all warnings for a member.
/purgeModSlash
w!purge <2–100>
Bulk delete messages in the current channel (up to 100).
/slowmodeModSlash
w!slowmode <seconds>
Set channel slowmode in seconds (0 to disable).
/lockModSlash
w!lock [#channel]
Lock a channel so @everyone cannot send messages.
/unlockModSlash
w!unlock [#channel]
Unlock a previously locked channel.
/note addMod
/note add @user <note>
Add a private staff note to a user's profile.
/note listMod
/note list @user
View all staff notes recorded for a user.
/softbanMod
/softban @user [reason]
Ban then immediately unban to delete recent messages.
/massbanAdmin
/massban <id1> <id2> ...
Ban multiple users by ID in one command.
/deafenMod
/deafen @user [reason]
Server-deafen a member in voice channels.
/undeafenMod
/undeafen @user
Remove server deafen from a member.
/nukeAdmin
/nuke [#channel]
Clone and delete a channel — wipes all message history.
/automod badwords addAdmin
/automod badwords add <word>
Add a word to the auto-mod filter list.
/automod badwords removeAdmin
/automod badwords remove <word>
Remove a word from the auto-mod filter.
/automod badwords listAdmin
/automod badwords list
View all currently banned words in the filter.
/automod spamAdmin
/automod spam <limit>
Set max messages per 5 seconds before spam detection triggers.
/automod antiinviteAdmin
/automod antiinvite on/off
Block Discord invite links from being posted in your server.
/automod offAdmin
/automod off
Disable all auto-moderation for this server.
/reactionrole addAdmin
/reactionrole add <msg_id> <emoji> @role
Attach a reaction role to any message — users react to get the role.
/reactionrole removeAdmin
/reactionrole remove <msg_id> <emoji>
Remove a reaction role mapping from a message.
/reactionrole listAdmin
/reactionrole list
List all active reaction roles in this server.
/role addMod
/role add @user @role
Manually add a role to a member.
/role removeMod
/role remove @user @role
Remove a role from a member.
/role infoSlash
/role info @role
View detailed information about a role.
/role membersSlash
/role members @role
List all members who hold a specific role.
/role colorAdmin
/role color @role <#hex>
Change the display color of a role.
/role createAdmin
/role create <name> [#hex]
Create a new server role with optional color.
/role deleteAdmin
/role delete @role
Permanently delete a role from the server.
/role hoistAdmin
/role hoist @role <on/off>
Toggle whether a role is displayed separately in the member list.
/role mentionableAdmin
/role mentionable @role <on/off>
Toggle whether a role can be @mentioned by everyone.
/muterole setAdmin
/muterole set @role
Set an existing role as the muted role for this server.
/muterole createAdmin
/muterole create
Auto-create and configure a Muted role with correct permissions.
/welcome setAdmin
/welcome set #channel <message>
Set welcome message with placeholders: {user}, {server}, {count}.
/welcome offAdmin
/welcome off

/joinrole addAdmin

/joinrole removeAdmin

/joinrole listAdmin
/joinrole list

/log offAdmin
